# tic-tac-toe-game
Play the classic Tic-Tac-Toe game with a simple, interactive interface, turn-based moves, instant winner detection, and replay functionality.

🎮 Tic-Tac-Toe Game
A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

✨ Features
🎯 Interactive 3×3 game board
❌ X and O turn-based gameplay
🏆 Automatic winner detection
🔒 Prevents clicking boxes after a move
🔄 Reset button to restart the game
🆕 New Game button to start a fresh match
💻 Simple and beginner-friendly JavaScript
🛠️ Technologies Used
HTML5
CSS3
JavaScript
🚀 How to Play
Open the game in your browser.
Click any empty box to make your move.
Players take turns placing X and O.
The first player to get three matching symbols in a row, column, or diagonal wins.
Click Reset or New Game to play again.
